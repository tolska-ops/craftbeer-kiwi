## Recently done (context only - safe to trim once this feels stale)

- ✅ **Regional dry-run pagination added, and the Thorndon/Petone question resolved** (28 July). A Nelson region dry run (first test of the new `?query=`/`?lat=`/`?lng=`/`?radius=` overrides, ahead of national expansion) surfaced Sprig + Fern as a known national pub chain with non-brewing satellite locations - prompting a check of whether Wellington's own Sprig + Fern pubs (Thorndon, Petone) were being missed due to the 20-result-per-request cap. Added pagination via `nextPageToken` (`MAX_PAGES = 4`, up to 80 candidates per run) to test this properly. Re-running Wellington confirmed `found` stayed at exactly 20 either way - not a volume problem. Real explanation: Thorndon and Petone are pubs that pour Sprig + Fern beer, not breweries, so Google's relevance ranking correctly doesn't return them for a "brewery" query - same pattern as Nelson's own non-Richmond Sprig + Fern locations. Pagination kept anyway (genuinely useful for larger regions, especially Auckland) even though it wasn't the fix for this specific case. Full writeup in `craftbeer-kiwi-decisions.md` (DEC-023).
- ✅ **Nelson region dry run - first regional test ahead of national expansion** (28 July). Confirmed working: 20 candidates found, correctly split into 5 genuine breweries (McCashins, Acoustic, Totara, Sprig + Fern Richmond, Eddyline Stoke) and 15 correctly-typed non-breweries (pubs, bars, restaurants, a museum, a bottle shop) via `primary_type`. Surfaced Sprig + Fern as independently-owned (confirmed via NZBN `9429034586907`, no corporate parent) but operating as a multi-region pub chain from a single Richmond brewery - added as a second, distinct angle on the open craft-curation question (see "In progress" above).
- ✅ **`dryRun` flag built and tested for `brewery-discover`** (28 July). `?dryRun=true` now returns `wouldInsert`/`skippedNames` without writing to `breweries`, closing out the hard blocker on national expansion. Immediately proved its worth: caught a real problem in the `includedType`/`strictTypeFiltering` test below before it touched live data.
- ✅ **Search-query narrowing tried and reverted** (28 July). Tested filtering `brewery-discover`'s Places search with `includedType: "brewery"` + `strictTypeFiltering: true` (Google's new Feb 2026 brewery type category), using `dryRun` to check results before trusting it live. Found it unreliable: only matched venues with "Brewery"/"Brewer" literally in their own name, missing 15 of 23 known breweries entirely (Panhead, Boneface, Three Sisters included). Reverted to the original broad query. Kept `primaryType`/`primary_type` (new column, DEV + prod) as triage metadata only, not a filter - correctly flagged "Teddy's Tacos: Taproom & Taqueria" as `primary_type: "restaurant"` on the very first test after reverting, confirmed by Andy as a bar/taproom, not a brewery. Full writeup in `craftbeer-kiwi-decisions.md` (DEC-022).
- ✅ **NZBN backfill across all 23 breweries** (28 July). Manually looked up and recorded `nzbn` + `nzbn_entity_name` for every brewery (bars excluded). Confirmed two genuine multi-site matches (Waitoa, Double Vision); found the "shared NZBN = same brand" theory breaks down for conglomerate-owned brands (Panhead/Lion, Tuatara/DB). Full findings in `craftbeer-kiwi-decisions.md`.
- ✅ **`is_published` flag + publish-gate constraint** (28 July). New `is_published` column plus a check constraint that makes it structurally impossible to publish a brewery without an explicit theme entry. All 23 existing breweries defaulted to published with zero constraint violations - nothing changed on the live map.
- ✅ **National expansion plan decided** (28 July). Region-by-region rollout, not a single national pass - Auckland and Canterbury first, then Waikato/Bay of Plenty/Otago, then the rest batched. `dryRun` is now a hard blocker on starting. Full plan in `craftbeer-kiwi-automation-plan.md`.

- ✅ **Supabase secret-key 401 issue resolved** (27 July) - not a platform bug. `@supabase/server`'s secret-key auth mode needs a *named* key (`auth: "secret:<name>"`); both Edge Functions had just `auth: "secret"`. Fixed by referencing the named key (`brewery_sync_v2`) and redeploying.

- ✅ **Geolocation fallback bug fixed** (27 July). Both failure paths (`!navigator.geolocation` and the `getCurrentPosition` error callback) previously fell back to a hardcoded Wellington CBD coordinate; now they leave `userLocation` as `null`, so the marker simply doesn't render rather than showing a misleading fake position. Also switched to `{ enableHighAccuracy: true, maximumAge: 0, timeout: 10000 }` to reduce the chance of a stale/cached low-accuracy fix being used. Directly addresses the 26 July Blenheim visitor report. Confirmed 28 July.
- ✅ **Zoom-dependent brewery name labels** (27 July). Native Mapbox symbol layer (`<Source>`/`<Layer>`) renders brewery names once zoomed in past `minzoom={14}` - chosen because it lines up with the existing pin-click `flyTo` zoom level, so labels tend to appear right around where users naturally land. Built on top of the existing pin/clustering system without changing it. Confirmed 28 July.
